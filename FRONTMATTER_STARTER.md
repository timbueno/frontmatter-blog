# Your Frontmatter blog

This starter uses Hugo Bear Blog (https://github.com/janraasch/hugo-bearblog),
licensed under MIT. Its license is included in themes/hugo-bearblog/LICENSE.
The theme snapshot comes from the Frontmatter LandingPage pilot, with the
modern Hugo locale template adjustment. No personal site content is included.

Edit the home page in content/_index.md. Your first post, content/blog/welcome.md,
is a draft. Frontmatter can edit it and create more posts under content/blog.
The theme is bundled locally, so builds do not follow a moving theme branch.

Before publishing, select GitHub Actions in Settings → Pages → Source, then run
Frontmatter Pages on your publication branch from the repository's Actions tab.
Private-repository Pages availability depends on your GitHub plan. Frontmatter
does not change repository visibility, Pages settings or custom domains later.
